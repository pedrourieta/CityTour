# CityTour – Guía turística interactiva

Aplicación Android hecha con Kotlin y Jetpack Compose para la actividad **AVS.03.04.01 Uso de recursos multimedia** de la asignatura Programación de Aplicaciones Móviles (UTEZ).

La app funciona como un museo virtual. En la sección de la **Catedral de Cuernavaca** se puede ver un carrusel de fotos y escuchar una audioguía con la historia del lugar.

## Funciones

- Carrusel de 5 imágenes con botones Anterior y Siguiente
- Audioguía con botones Play, Pausa y Stop
- Control de volumen
- El audio se detiene al regresar a la pantalla de inicio

## Recursos multimedia

- `app/src/main/res/drawable-nodpi/`: imágenes del carrusel (JPG)
- `app/src/main/res/raw/narracion_catedral.mp3`: narración (MP3 mono, 64 kbps)

## Cómo ejecutarla

1. Clonar el repositorio y abrirlo en Android Studio.
2. Esperar a que Gradle sincronice.
3. Ejecutar en un emulador o celular con Android 8.0 o superior.
